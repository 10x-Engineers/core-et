== Excluded on purpose

These items were in earlier drafts but are not in the chapter, because no source in this repository verifies them, or because the only source is the presentation:

* process node, transistor count, die area, package, power figures and core frequencies;
* the "over 160 million bytes" SRAM figure (DS gives 140 MB);
* the ET-Maxion micro-architectural numbers (fetch width, ROB size, cache sizes);
* the Scope of This Document section (the CPU Subsystem facts are reused in Chapter 13);
* source citations in figure captions (sources are kept in this trace instead);
* the host/card deployment section, the website card photo, the host software stack and the PCIe add-in card example.
