== Chapter division

Only blocks that exist in the RTL of this repository get a chapter. Blocks without code are mentioned only in Chapter 1, and only for context.

Order:: Data Cache comes before VPU. The VPU uses the data cache for vector load/store, scratchpad access, tensor load and reduce, so describing the data cache first avoids forward references.

== Standard chapter template

Chapters 2–13 follow this template for each block they describe. A section is left out when it does not apply to the block.

. *Overview*: what the block does and where it sits.
. *Block diagram*: sub-blocks and the main data and control paths.
. *Interfaces*: an I/O signal table. Each row is marked *Full* (traceable in the RTL, described in detail) or *Brief* (driven from outside the scope or tied off, described only by the logic it drives).
. *Data structures*: struct and packet tables (field, width, meaning).
. *Parameters*: the defines and parameters that size the block, with their values.
. *Functional description*, per sub-block:
** pipeline stages;
** buffering;
** arbitration;
** FSMs, with state diagrams.
. *Operation flows*, with timing diagrams (WaveDrom):
** the normal case;
** backpressure and stall;
** flush and kill.
. *Reset and configuration*: reset values, ESR/CSR controls.
. *Errors and exceptions*: detection, reporting, ECC.
. *Performance*: latency, throughput, PMU events.
. *Corner cases and known RTL/legacy differences*.
. *Verification notes*: key scenarios and checkers worth targeting.
